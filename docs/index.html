What the independent checker establishes

Every parent edge matches a separately implemented rule template at its recorded tree path. Parent chains prove reachability. Closure checks every legal outgoing rewrite; distance inequalities plus those paths prove shortest distances. A separate full grammar census uses exact evaluation on a 5×5 integer grid. Every term has degree at most four in either variable, so equality at those 25 points proves a polynomial identity over all rational x and y. This is a finite-degree identity argument, not an empirical sampling claim.

Browser evidence is not independently checked until the Python verifier accepts the downloaded JSON. The generator uses polynomial coefficient maps; that verifier uses neither the generator nor those maps.

Scope & attribution

Finite on purpose. Exact about what is missing.

Ordered binary expression trees over leaves 0, 1, x and y, with + and *. No subtraction, division, arbitrary constants, variables beyond x/y, tensor shapes or floating point. The intermediate node budget is 3, 5 or 7. Every addition, multiplication and leaf occurrence has an integral cost from 1 to 8. The entire grammar contains 36, 548 or 10,788 terms. No timeout or silent truncation changes the result.

Rules are bidirectional commutativity, associativity, additive-zero and multiplicative-one identities, zero annihilation and left/right distribution/factoring. A reverse zero rewrite may introduce any fitting term from the full grammar. Exactly one rule acts at exactly one subtree per step. The proof budget counts all tree nodes, including repeated occurrences. Full closure includes non-improving and cyclic rewrites. The semantic optimum is limited to the same finite grammar, not arbitrary expressions outside it.

This is an explicit bounded term-rewrite graph, not an e-graph or an implementation of egg, TENSAT, TASO, Herbie or Alive2. Those systems supply context for compiler optimization, graph rewriting and validation. It has no neural model, learned policy, tensor execution, GPU benchmark, runtime-speedup, new algorithm or production-compiler-equivalence claim. Exact rational identities need not preserve IEEE floating-point behavior. See CONTRACT.md and SOURCES.md in the source repository.
